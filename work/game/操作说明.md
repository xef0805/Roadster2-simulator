# Roadster Flight Lab v0.1.6

双击 RoadsterLab.exe 直接运行，无需安装 Godot。默认无边框全屏。

## 本版更新

- 重新制作低矮 Roadster 风格车身：弧面轮廓、轮拱开口、流线黑色玻璃座舱、独立前灯与红色尾灯带。车外以完整车身轮廓为主；驾驶舱保留机器人手臂。
- 高空按空格仍有较细的气柱、喷口提示与声音。垂直升力仅用于近地短时起跳和下降缓冲，高空无法持续升高；高空喷气不会抵消重力或延长滞空。
- 右键环顾支持完整环绕与更大的俯仰范围，鼠标捕获后不受屏幕边缘限制。滚轮调节车外观察距离，松开右键后平滑归位。
- 右上角加入固定水印：GitHub / 抖音 Felix_0805，回放中也保留。
- 自动记录最近一次完整起飞、空翻动作，提供可暂停、拖动时间轴的三维自由视角回放。

车辆、喷气、吸附和辅助参数用于游戏，不代表真实 Tesla 技术规格。模型为自制简化模型，音效为原创合成。

## 驾驶按键

| 按键 | 作用 |
|---|---|
| W | 地面加速；空中水平向前推力 |
| S | 地面刹停并保持；停稳后松开、再按 S 倒车；空中消减水平速度 |
| A / D | 转向；空中调航向 |
| Shift | 手刹漂移；松开后恢复抓地 |
| 空格 | 地面短时弹起，下降接近路面后缓冲；高空只显示喷气 |
| Q / E | 空中左右横滚，松开后辅助转正 |
| F | 吸附开关，默认开启 |
| C | 车外跟随 / 驾驶舱 |
| 鼠标右键拖动 | 360° 环顾与俯仰，松开后平滑归位 |
| 鼠标滚轮 | 拉近 / 拉远车外观察距离 |
| Tab | 查看或退出最近一次完整动作回放 |
| R | 回到当前场景起点 |
| Esc | 暂停、选择场景起点、退出游戏；回放中为返回驾驶 |

## 起飞与落地

平地按住空格，提供最多约 0.8 秒的起跳喷气。推力随离开路面的距离减弱，在离地约 3—5 米时逐渐关闭；之后按惯性、重力和空气阻力继续运动。没有强行固定高度的位置墙。

下降到有效地面或障碍物表面上方约 6 米内时，按空格可缓冲。高空长按或反复点按均不能续升；松开立即切断垂直推力。落地后一直按住空格不会自动弹起，落稳后松开再按才能重新起跳。

近地喷气会扬起白雾，离地后白雾留在地面消散，高空只保留较细气柱。

倒挂坡道：默认起点。保持吸附，沿白线加速爬升，离开末端后沿坡道方向继续翻转。离开后松开 W，必要时按 S 降低水平速度，接近地面时按空格缓冲。低速离开可能直接下落。

飞越车队：按 Esc 选择对应起点。沿白线加速，车队前提前按空格起跳，保留高于 Semi 的净空；可在越障过程中按 Q/E 横滚，留出转正时间。越过后松开 W，按 S 减速，近地按空格缓冲。五辆障碍车为 Cybercab、Cybertruck、Semi、Model Y、Model 3 的简化模型。

漂移：在开阔平地加速后转向，短按 Shift 约 0.3—0.6 秒，再松开手刹并适当反打收车。长时间同时转向和拉手刹会继续甩尾、减速。

## 回放操作

起飞时自动录制，落地约 0.8 秒后保存，包含起飞前约 1 秒。左上角显示“已保存”后按 Tab 查看。只保留本次运行最近一次完整动作，最长约 60 秒，退出游戏后不保留，也不导出视频。

| 回放按键 | 作用 |
|---|---|
| 鼠标右键拖动 | 自由转动镜头 |
| W / A / S / D | 沿镜头方向前后左右移动 |
| Q / E | 镜头下降 / 上升 |
| Shift | 加快镜头移动 |
| 滚轮 | 调整镜头移动速度 |
| P | 暂停 / 播放；暂停时也可自由移动镜头 |
| J / L | 前退 / 后进一秒 |
| 时间轴 | 鼠标拖动查看任意时刻 |
| Tab / Esc / 返回驾驶按钮 | 退出回放，回到原来的驾驶位置与速度 |

回放保存车身轨迹、姿态、转向、悬架和喷气状态；烟雾粒子会重新生成，因此细节不保证与第一次逐粒一致。录像播放不重新模拟车辆物理，也不会改变原驾驶状态。尚未完成起飞落地时，会提示没有可看的完整录像。

## 仪表

左下为 G 值和速度，左二为相对世界水平的三维姿态球。右侧喷口图表示实时排气方向，右下 ALTITUDE 为相对平地基准的高度，单位米；小字保留接地轮数和吸附开关。

G 值为非重力载荷：平地静止约 1G，自由下落约 0G。LIFT 为实际近地升力开度；高空按空格时喷口可以点亮，而 LIFT 仍为 0，表示只有喷气表现。ALTITUDE 不是喷口到附近坡面或障碍物的距离。
